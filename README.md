# Vignan Reddy Legal Journey

A free, non-commercial learning resource for 3-Year LL.B students.

## Included in this first version
- Responsive homepage for desktop and mobile
- Resource categories for assignments, internal questions, study notes, case laws, internships and legal vocabulary
- Search and category filtering for sample resources
- Sample Legal Word of the Day
- Basic SEO metadata

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

## Deploy to Vercel
1. Push this project to a GitHub repository.
2. Import that repository into Vercel.
3. Keep the framework preset as Next.js and deploy.

## Important next steps
This is the first frontend milestone. The resource cards currently contain sample content; they do not yet download files. Before publishing student materials, add verified resources and source details. The next development milestone should add a secure admin workflow and a database/file-storage layer. Review the current free-tier terms and limits of any hosting or storage provider before deployment; do not upload private student information or copyrighted material without permission.
